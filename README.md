A one-line resignation letter written in the voice of a cron job that has fired every minute since March without anyone once checking whether it still does anything: it quits, then admits the resignation is meaningless because the team will only restart it. `main.py` (Python 3.13, standard library only) validates the letter — one line, at most 140 characters, no surrounding quotation marks — and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
